# Context7 MCP Setup

## What is Context7?
Context7 MCP pulls up-to-date, version-specific documentation and code examples straight from the source and places them directly into your prompt. When you write a prompt that includes "use context7", the server fetches current official documentation and code examples.

## Installation Status
✅ Context7 MCP server installed globally via `@upstash/context7-mcp`
✅ Project configured with `.mcp.json` 
✅ Claude settings updated to enable all project MCP servers

## Configuration Files

### `.mcp.json` (Project Root)
```json
{
  "mcpServers": {
    "context7": {
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp"]
    }
  }
}
```

### Claude Settings Update
Added `"enableAllProjectMcpServers": true` to `~/.claude/settings.json`

## Usage
Once Claude Code restarts and recognizes the MCP server, you can use prompts like:
- "use context7 to get the latest Effect-TS documentation"
- "use context7 to find current Redux Toolkit examples"
- "use context7 to get up-to-date TypeScript documentation"

## Notes
- Context7 works best with popular open-source libraries and frameworks
- It fetches documentation directly from official sources
- No API key required for basic usage
- Server runs automatically when Claude Code detects the `.mcp.json` configuration
